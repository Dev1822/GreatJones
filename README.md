# Great Jones Website

A simple **Great Jones website** built using **HTML and CSS**.  
This project recreates the look and feel of an e-commerce style website with pages for Home, About, New Products, and Sale items.

🌐 **Live Demo:**  
https://devpatel-greatjones.netlify.app/

---

## Features

- E-commerce styled UI
- Multiple pages (Home, About, New, Sale)
- Shared CSS styling using common.css
- Responsive layout
- Simple and organized structure

---

## Tech Stack

**Frontend**
- HTML5
- CSS3

**Tools**
- Git
- GitHub
- Netlify (Deployment)
